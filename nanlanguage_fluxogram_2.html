1. Entry

Project Goal

Lightweight interpreted scripting language in C++ for learning interpreter design, parsing, variables, loops, recursion, and script execution.

build

Compile Interpreter

g++ -std=c++17 nanLanguage.cpp -o nanLanguage

run

Execute Script File

./nanLanguage program.txt

  • Input is a line-based .txt script
  • If no file is provided, usage message is shown
2. Interpreter Core

Load Program

Read the full file into memory, then split it line by line.

parse

Parse Instruction

Take the first token of each line as the command name.

dispatch

Command Dispatcher

Match the parsed token to a supported command and execute the corresponding behavior.

state

Runtime State

Variables are stored as integers in a map structure and reused across execution.

std::map<std::string, int>

3. Supported Commands

Command Set

print

Outputs quoted text or a variable value.

set

Creates or updates integer variables.

add

Adds a numeric value to an existing variable.

comment

Ignores the line when spelled correctly.

iterate

Loop Execution

loop variable:count ( ... )

  • Starts at 0
  • Stops before count
  • Assigns the loop variable automatically
  • Uses recursion to execute the loop block
output

Program Output

The interpreter prints results as each instruction is executed.

4. Gaps and Next Steps

Current Limitations

  • No string variables
  • No expression parsing
  • No conditionals
  • No functions
  • No file I/O
  • Weak syntax validation
  • No error recovery
evolve

Roadmap

  • Add if conditionals
  • Add function definition and calls
  • Add math expression parsing
  • Add string variable support
  • Add file read/write
  • Add line-numbered error reporting
  • Add stronger nested block validation
  • Add optional AI API integration
value

Educational Outcome

Good foundation for building a scripting language, compiler, VM, or DSL while learning tokenization, parsing, recursion, and state management.
