Getting Started

Requirements:
• C++ Compiler (g++ / clang)
• C++11 or later

Compile:
g++ -std=c++17 nanLanguage.cpp -o nanLanguage

Run:
./nanLanguage program.txt

Errors:
• variable not found
• division by zero
↓

Main Execution Flow

Goes line-by-line while maintaining state.

Script File → Read File → Parse → Execute → Output

Uses istringstream to split lines
↓
Block Command?
(loop / if)
or Standard Line?
readBlock()

Extracts code inside (...)

How it works:
• Tracks nesting depth
• "(" → depth +1
• ")" → depth -1
• Stops when depth = 0

Purpose:
Ensures correct parsing of nested blocks
↓
Recursive execute()

Enables:
• Nested loops
• Conditionals
• Recursion
runLine()

Executes single-line commands

Steps:
• Parse command + arguments
• Identify command type
• Execute logic

Handles:
• print → output
• set → assign value
• add/sub/mult/div → math ops
↓
print → output
set → assign
add/sub/mult/div → math
↓
State Management

• Variables stored in map
std::map<string, int>

• Persistent values
• Dynamic updates
↓
More Lines Remaining?
YES → Continue Loop
Execute next line
NO → End Program
Output final result
↓

Gaps & Limitations

Data Types:
  • Integers only
  • No float, bool, or string
Performance:
  • Re-parses each loop
  • Slower execution
Errors:
  • Basic messages only
  • No line tracking
Memory:
  • Global variables only
  • No scope system
↓
